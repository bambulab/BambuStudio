The SolidWorks MBD 2018 fixture is NIST's FTC 06 PMI test part, from:
https://www.nist.gov/system/files/documents/noindex/2024/05/07/NIST-FTC-CTC-PMI-CAD-models.zip

NIST permits use of these test files without restrictions and requests acknowledgement:
https://www.nist.gov/ctl/smart-connected-systems-division/smart-connected-manufacturing-systems-group/mbe-pmi-0

The native part is retained, rather than a pre-converted mesh, to exercise the
container, decompression, descriptor tables, triangle strips and metre-to-mm
conversion. Its saved mesh bounds are 304.8 x 97.79 x 247.65 mm. This fixture
also contains PMI; it is not a guarantee that every CAD version/configuration
or saved display cache is complete or watertight.

No user-owned CAD files are included in this test data.
