## Contract rules that JSON Schema does not fully express

`McpToolsManifest.json` is generated with Zod-to-JSON-Schema (`jsonSchema7`, no refs). Native validation must also preserve these runtime predicates from the original TypeScript registry:

- Shared `path` validator requires an absolute path and rejects NUL. It affects project paths, imports, captures, and exports that use `path`.
- `model.import_multipart`: each path must end in `.stl` or `.obj`.
- `object.transform`: at least one of `position`, `rotation`, or `scale` is required.
- `plate.delete`: `targetPlateIndex` is required only when `contents="move"`, and forbidden otherwise.
- `view.capture`, `export.geometry`, `export.gcode`, and `export.sliced_3mf`: destination suffix must respectively be `.png`, `.stl`/`.obj`, `.gcode`, and `.gcode.3mf`.
- `settings.effective`: a plate filter requires `expectedPlateRevision`; a volume filter requires `objectId`.
- `settings.update` and `settings.override`: values must contain 1–100 entries. `settings.override` also requires exactly the identifiers for its selected scope.
- `object.cut`: plane normal must not be all zero.
- `object.merge`, `painting.set`, and `slice.start_batch`: the ID, face-index, or plate-index arrays must contain unique values.
- `ams.mapping.plan`: at least one AMS mapping is required.
- `calibration.start`: at least one calibration routine must be selected.
- `vector` and numeric values include finite/range checks; JSON Schema serialization may not preserve every JavaScript finite-number predicate. Native checks remain authoritative.

The old native source confirms additional behavior guards: stable session-scoped model/instance/volume IDs, plate and mesh revision guards, tracked job outcomes, stale-result rejection, workspace/modal/busy mutation gating, explicit confirmation for device actions, and disabled-by-default device actions/account reads. See the corresponding old native files indicated in the table.
