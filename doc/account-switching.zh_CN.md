# 多账号登录

修改基础为 Bambu Studio `2.8.2.61`，对应标签 `v02.08.02.61`。

1. 打开首页，已经登录的账号会自动加入左侧的“已保存账号”列表。
2. 点击“添加账号”，在拓竹登录窗口中完成另一个账号的登录。
3. 点击列表中的账号名称，即可切换到该账号。当前账号会显示“当前账号”。
4. 点击其他账号旁边的移除按钮，可以删除该账号保存的登录状态。
5. 使用原有的退出登录按钮，会退出当前账号并移除该账号保存的登录状态。

切换时，程序会保存当前账号的认证状态和上次选择的设备，并加载目标账号的设备、预设和网页资料。存在尚未保存的预设修改时，程序会询问如何处理这些修改。取消添加账号后，当前账号继续使用。

多设备发送任务仍在排队或上传时，需要等待任务完成，或者在原有任务页面取消任务后切换账号。

登录状态失效的账号会显示“重新登录”。完成登录后，程序会更新该账号保存的认证状态。

账号记录保存在当前 Bambu Studio 数据目录中的 `saved_accounts.dat`。Windows 使用当前 Windows 用户的 DPAPI 加密整个文件。文件内容包含网络插件原生认证文件的完整字节、账号名称、服务器区域和设备选择。认证文件由网络插件读取。
